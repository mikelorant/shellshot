# shellshot logo assets

| File | What |
| --- | --- |
| `logo-mark.svg` | Neon filmstrip mark, transparent; for dark backgrounds. |
| `logo-light.svg` / `logo.svg` | Lockup (mark + `shellshot` + cursor) on a black rounded badge, for light pages (`logo.svg` is a copy). |
| `logo-dark.svg` | Same lockup, transparent, for dark pages. It has the badge's viewBox, so both variants display at the same size. |
| `social-preview.png` | 1280x640 GitHub social card (lockup on black). |
| `showcase.svg` | README image: an animated SVG of the agent demo, generated by `make showcase` (not a logo asset). |

Palette: cursor amber `#feb102`, word `#fee48a`, outline gradient `#ffdcc8` to `#fcc400`, film holes `#fee482`, screen `#050100`, badge and card black `#000`.

Construction: a wavy neon film strip whose centre frame is a terminal screen with a `>` prompt and a block cursor.
Two side frames run off the ends.
The wordmark is JetBrains Mono Bold outlined to paths (no font needed), with an amber block cursor after it.

README top (the logo is the page title, centred, and the `id` is the target of the back-to-top links):

```html
<h1 id="shellshot" align="center"><picture><source media="(prefers-color-scheme: dark)" srcset="docs/assets/logo-dark.svg"><img alt="Shellshot" src="docs/assets/logo.svg" width="360"></picture></h1>
```
